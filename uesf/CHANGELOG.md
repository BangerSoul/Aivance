# UESF Changelog

All notable changes to the UESF framework. Format: [Keep a Changelog](https://keepachangelog.com/).
Versioning: [docs/versioning.md](docs/versioning.md).

## [1.0.0] — 2026-08-07

### Added

- **Framework core:** 15-layer architecture; 31-category taxonomy; design
  philosophy (12 axioms); repository structure with purpose rules.
- **41 skills:** 6 core primitives (planning, implementation, testing, debugging,
  review, refactoring), 13 engineering, 7 AI/UX/UI, 13 meta-skills, 2 examples —
  all spec-conformant and validated.
- **Specification:** UESF Skill Specification v1.0.0 (24 frontmatter fields + 10
  required body sections) with machine-readable JSON Schema.
- **Tooling:** stdlib-only validator (spec enforcement, dependency resolution,
  cycle detection, `--list`/`--graph`/`--json`) and skill scaffolder.
- **Test suite:** 14 tests with fixtures covering valid and every invalid class.
- **Meta layer:** 13 meta-skills closing the self-improvement loop.
- **Deliverables:** all 20 v1.0.0 deliverables (analysis, architecture, knowledge
  graph, taxonomy, dependency graph, spec, migration, versioning, testing,
  certification, continuous learning, automation, benchmarks, roadmap, future
  extensions, repository, certificate).
- **Supporting assets:** workflows, policies, MCP manifest, integrations guide.
- **Certification:** v1.0.0 certificate — 41 skills, 0 errors, 0 warnings,
  14/14 tests.
